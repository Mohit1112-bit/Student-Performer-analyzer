# 📊 Student Performance Analyzer

A Python-based data analysis project that analyzes students' academic performance using **NumPy, CSV, and Python file handling**. It generates useful insights into students' marks, attendance, and study hours.

## 🚀 Features

- 📁 Import student data from a CSV file.
- 📚 Analyze students' marks across different subjects.
- 📈 Calculate average marks and identify top-performing students.
- 🕒 Analyze attendance and daily study hours.
- 🔗 Calculate the correlation between study hours, attendance, and academic performance.
- 📝 Generate a performance report in a text file.
- ⚠️ Identify students who may need academic improvement.

## 🛠️ Technologies Used

- **Python** — Core programming logic
- **NumPy** — Numerical calculations and statistical analysis
- **CSV** — Data storage and importing student records
- **File Handling** — Exporting analysis reports to a text file
- **Git & GitHub** — Version control and project hosting

## ⚙️ How to Run

1. Install Python 3.
2. Install NumPy:

   ```bash
   pip install numpy
   ```

3. Clone this repository:

   ```bash
   git clone https://github.com/Mohit1112-bit/Student-Performer-analyzer.git
   ```

4. Open the project folder:

   ```bash
   cd Student-Performance-Analyzer
   ```

5. Run the program:

   ```bash
   python main.py
   ```
